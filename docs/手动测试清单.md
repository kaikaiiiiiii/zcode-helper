# ZCode 端手动测试清单（只测必须手动的）

> 自动化已覆盖 55 个单元 + 53 个 DOM 用例（滤网、灯条、状态机、侧栏解析、附件解析、新建会话定位等）。
> 这里只列**必须真机点、自动化测不了**的：真实发送、真实文件、真实键鼠、真实并发。
>
> 版本：**v0.5.13**。前置只有两条：设置里 **允许同时进行的会话数 = 2**、**防打扰 = 5**；队列窗口打开别关。

---

## 1. 图片附件（已有对话）

- 开**消息阻断** → 在任意对话点输入框左下角「+」→ 选 **「附件」** → 选一张本地图片 → 输入 `图1` → 回车。
- **通过**：队列里那条**显示缩略图**；关阻断后，图片和文字都进了对话。
- **失败**：队列里没图 / 回放后只有文字。

## 2. 压缩包附件（已有对话）

- 同 1，但挂一个 `.zip` 或 `.rar`，文字 `包1`。
- **通过**：队列条目标题是**文件名**（如 `xxx.zip`）；关阻断后对话里出现**文件卡片**。
- **失败**：队列里附件为空 / 回放后只有文字。

## 3. 粘贴的截图

- 开阻断 → 按 `Ctrl+V` 粘贴一张剪贴板截图（不要用文件选择器）→ 输入 `图2` → 回车。
- **通过**：队列显示这张图；关阻断后图片正常进对话。

## 4. 新建会话（选了项目）

- 开阻断 → 侧栏**鼠标悬停项目名** → 点最右侧圆形加号「新建任务」→ 确认输入框上方胶囊是**该项目名** → 挂一张图 → 输入 `新会话1` → 回车。
- **通过**：队列条目带「新会话」标签、项目名正确；关阻断后 helper 自动在该项目开新会话并发出（侧栏多出一个对话，里面有图）。
- **失败**：报 `new-session-*` 或发到了别的会话。

## 5. 新建会话（任务分区）

- 开阻断 → 侧栏**「任务」分区标题**悬停 → 点圆形加号 → 胶囊应显示**「选择项目」** → 输入 `新会话2` → 回车。
- **通过**：队列条目项目显示「选择项目」；关阻断后**任务分区**下出现新对话，里面有这条消息。

## 6. 并发排队（真实 working 数）

- 设置里把 **N 改成 1** → 在对话 X 发个要跑一会的任务（如 `从1数到200`）→ 灯条显示 `1 / 1` → 到对话 Y 发 `排队1`。
- **通过**：`排队1` 没立刻发出、进队列、灯条变黄；X 跑完后几秒内自动发出。
- 测完 **N 改回 2**。

## 7. 防打扰（真实键鼠）

- 确保防打扰 = 5 → 开阻断 → 发 `打扰1` → **关阻断的同时立刻在浏览器/记事本里连续打字 10 秒**。
- **通过**：你打字期间它一直不发；停手 5 秒后才发出。

## 8. 消息阻断端到端

- 开阻断 → 发 `阻断1` → **通过**：输入框清空、消息不出现、队列里带「消息阻断」标签；关阻断后自动发出。

## 9. 输入框有草稿时回放

- 开阻断 → 在对话 A 发 `第一条` → 不关阻断，继续在输入框打半句 `没写完`（不要回车）→ 关阻断。
- **通过**：`第一条` 发出；半句变成队列里的**「草稿」**条目（点「上屏」能放回输入框）。

## 10. 红点自动「继续」（条件触发，可跳过）

- 让某个对话**出错结束**（断网 / 模型报错），侧栏出现**红点**。
- **通过**：队列最前面出现内容为 `继续`、来源 `auto` 的条目；同一对话不重复插；5 分钟内最多 3 条。

## 11. 灯条拖动与吸附

- 拖到右下角松手 → 吸附；拖到左侧中部松手 → 吸附左边垂直居中；拉伸 ZCode 窗口 → 不跑出屏幕；单击灯条 → 面板开合。
- **通过**：四个角/四条边都能吸；重启 helper 后位置保留。
